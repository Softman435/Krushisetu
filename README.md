# 🌾 KrushiSetu – Farmer to Customer Platform

KrushiSetu is a web-based agricultural platform designed to connect farmers directly with customers. It aims to reduce unnecessary middlemen and help farmers sell their products at fair prices.

## 🎯 Project Objective

To create a digital platform where farmers can list agricultural products and customers can purchase them directly.

## ✨ Key Features

- Farmer and customer accounts
- Farmer product management
- Product categories and grading (A, B, C)
- Fixed-price product listings
- Shopping cart and wishlist
- Order placement and tracking
- Order cancellation
- Customer address management
- Cash on Delivery and online payment integration
- Farmer wallet and withdrawal functionality
- Admin management

## 🛠️ Technologies Used

**Frontend**
- HTML
- CSS
- JavaScript

**Backend**
- Node.js
- Express.js

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/Softman435/Krushisetu.git
```

### 2. Open the project

```bash
cd Krushisetu
```

### 3. Install backend dependencies

```bash
cd backend
npm install
```

### 4. Configure environment variables

Create a `.env` file in the backend folder and configure your database and required API credentials.

### 5. Start the backend

```bash
node server.js
```
